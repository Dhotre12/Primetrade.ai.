# Crypto Sentiment & Trading Behavior Analysis

This project analyzes the relationship between market sentiment (measured by the **Fear & Greed Index**) and **trader performance** (PnL, Win Rate, Volume). It includes a Jupyter Notebook for deep-dive statistical analysis and a Streamlit dashboard for interactive exploration.

## 📂 Project Structure

```text
├── analysis_main.ipynb       # Main analysis notebook (Data Prep, EDA, ML Models)
├── app.py                    # Streamlit Dashboard code
├── historical_data.csv       # Input: Raw trading data (User provided)
├── fear_greed_index.csv      # Input: Sentiment data (User provided)
├── processed_daily_data.csv  # Output: Generated by notebook for the dashboard
└── processed_trader_stats.csv# Output: Generated by notebook for the dashboard

```

## 🚀 Setup & Installation

### 1. Prerequisites

Ensure you have Python 3.8+ installed.

### 2. Install Dependencies

Install the required Python libraries using pip:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn streamlit plotly

```

### 3. Data Preparation

Place your raw data files in the root directory:

* `historical_data.csv`: Contains trade executions (Timestamp, Side, PnL, Size, etc.).
* `fear_greed_index.csv`: Contains daily sentiment values.

---

## 📊 How to Run

### Step 1: Run the Analysis

Open and execute the Jupyter Notebook to process the data, generate insights, and create the export files required for the dashboard.

1. Open the notebook:
```bash
jupyter notebook analysis_main.ipynb

```


2. Run all cells.
* **Note:** The final cells in the notebook export `processed_daily_data.csv` and `processed_trader_stats.csv`. These are required for the dashboard to work.



### Step 2: Launch the Dashboard

Once the processed CSV files are generated, run the Streamlit app:

```bash
streamlit run app.py

```

This will open a local web server (usually at `http://localhost:8501`) where you can interactively explore:

* Daily PnL vs. Sentiment.
* Volume trends during Fear vs. Greed.
* Trader segmentation clusters.

---

## 🧠 Key Features

### Part A: Data Pipeline

* **Merges** trading logs with daily sentiment scores.
* **Calculates** daily metrics: Net PnL, Win Rate, Total Volume, Active Trader Count.

### Part B: Analysis & ML

* **Segmentation:** Classifies traders into "Whales", "Retail", "Consistent Winners", etc.
* **Clustering:** Uses K-Means to find behavioral archetypes based on frequency and size.
* **Prediction:** A Random Forest model predicts next-day profitability based on current sentiment and volume.

### Part C: Strategy Insights

The analysis provides actionable rules, such as:

* **"Fade the Hype":** Shorting during "Extreme Greed" showed higher win rates in historical tests.
* **"Panic Liquidity":** High-volume scalping opportunities identified during "Extreme Fear" days.
